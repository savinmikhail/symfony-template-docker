# Persistent CI builder cache

The composite builder keeps bounded BuildKit state per repository, runner and PR/trusted boundary. GC targets 8 GB maximum, 1 GB reserved and 15 GB host free space; these are GC targets, not filesystem quotas. Trusted tag builds export registry cache, and PR jobs can read it without writing it. Hosted ubuntu-latest remains the template default, with no cross-machine local persistence; self-hosted products receive the persistent-state benefit.

Execution: CI PHP image -> independent dev gates -> production build once -> fresh Scout -> push checked local image -> existing Release candidate/deploy. Backend quality retains the exact eight Make targets in a fail-fast:false matrix: Composer validate/audit, PHPStan, PHPat, dependency analyser, PHP-CS-Fixer, Rector and production DI. PHPUnit remains separate with database creation, migrations and Doctrine schema/up-to-date validation. Frontend install/audit/lint/stylelint/build and KICS remain unchanged. Compose project names include run, attempt and check; Make command-line arguments preserve isolation even if an included .env.local sets a project name. CI overrides already remove shared host DB/Redis/RabbitMQ ports.

Existing Scout policy stays fixable High/Critical, with fresh vulnerability evaluation and retained SARIF. Its SBOM and fanal index directories are isolated per run/attempt/job/image, including XDG_CACHE_HOME. The same loaded image is pushed after passing Scout; there is no second production build. Existing full-release boundary, checked SHA/latest-tag candidate validation, serialized rollout, smoke/rollback and template no-production exclusion remain unchanged. No product module or notification secrets are introduced.

For dedicated CI hosts only, centrally schedule scripts/ci/runner-maintenance.sh. It skips active Runner.Worker processes, prunes unreferenced images older than 72 hours and removes disposable UUID builders older than 48 hours. Named ci-* builders remain. Never run this on production or independently in each repository job.
